# Port Scanner Project

## Overview
This is a simple **Port Scanner** project built using **Python (Flask)** for the backend and **React** for the frontend.  
The project allows users to enter an IP address or domain name and scan common ports to see which ports are **OPEN** or **CLOSED**.  
The Flask backend performs the actual port scanning, while the React frontend provides a **friendly GUI** in the browser.

---

## Features
- Scan multiple ports including common ones like 21, 22, 80, 443, etc.
- Returns port status as **OPEN**, **CLOSED**, or **ERROR**
- React frontend with a simple and intuitive interface
- Backend API is built using Flask and supports JSON requests
- Backend can be deployed on platforms like **Render**, frontend on **Vercel**
- CORS enabled for easy frontend-backend communication
